# Sarita Girls Hostel — A Home Away From Home

Welcome to the official website repository for **Sarita Girls Hostel**, Ranchi's premier, secure, and modern residential hostel for students and working women.

## 🌟 Key Features
- **Prime Location:** Located in Saket Vihar, Kadru, Ranchi – just 200m walking distance from DAV Kapil Deo School.
- **Modern UI/UX:** Built with sleek glassmorphism, responsive mobile layout, interactive photo gallery, and dynamic testimonials.
- **WhatsApp Direct Booking:** Seamlessly redirects room booking and campus visit inquiries to WhatsApp with pre-filled user form data.
- **Fully Responsive:** Perfectly optimized for desktops, tablets, and mobile devices with zero horizontal scroll.

## 📁 Project Structure
- `index.html` – Main Home Page with Hero section, Trust & Excellence strip, and Testimonials.
- `about.html` – Our Story, Mission, Warden Message, and Student Life.
- `gallery.html` – Full Campus & Room Photo Gallery with Lightbox viewer.
- `contact.html` – Location Map, Direction Guide (Railway Station 3.1 km, Airport 7.3 km), and Direct WhatsApp Inquiry Form.
- `style.css` – Complete responsive design system and modern CSS styling.
- `script.js` – Interactive navigation, modals, FAQs, toast notifications, and WhatsApp form redirection handlers.
- `images/` – Collection of hostel rooms, exterior, and campus photos.
